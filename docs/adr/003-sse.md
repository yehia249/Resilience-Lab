# ADR 003: Server-sent events

Status: accepted for implementation; verification is tracked in STATUS.md.

## Decision

Use browser EventSource with bounded clients, heartbeat, backlog protection and reconnect backoff.

## Reason

The dashboard needs one-way server updates once per second; bidirectional session state is unnecessary.

## Consequences

SSE must pass unbuffered through the reverse proxy. Lost connections retain last known state and are clearly labelled.

# ADR 002: k3s instead of managed Kubernetes

Status: accepted for implementation; verification is tracked in STATUS.md.

## Decision

Run a single-node k3s cluster on an Always Free ARM VM and use k3d locally.

## Reason

Managed control planes and managed databases can create charges; a small control plane makes the system inspectable.

## Consequences

The node remains a single point of failure. No host or zone availability claim is made.
